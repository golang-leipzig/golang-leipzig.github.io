What a difference a year makes

We just held meetup #61 on 2026-10-27 in Halle (Saale). About a year ago, we had a drinkup #54 on 2025-09-30. The wrap-up blog post for #54 demos the crush agent running qwen3-coder:30b with ollama, on an RTX 4000 SFF “Ada” GPU with 20GB VRAM.

If you squint, you can see a tiny bit of agentic coding happening. Claude code was released about seven months earlier on 2025-02-24, and accelerated the move to agentic coding. Harnesses were built, models improved.

Today, it is possible can run the pi or zot (Go) agent harness with e.g. with the open source strix halo engine gufo (or halogen (LICENSE)) with Qwen3.8-Flash-Next on an AMD Ryzen AI Max 395+ in a Framework Desktop (FWD) with 128GB LPDDR5x-8000:
